# Registro de progreso y avance

Usa esta carpeta para centralizar el seguimiento del desarrollo de tus proyectos de automatización.

## Organización

- `TIA_PORTAL/`: avances de programación PLC, HMI, redes y diagnósticos.
- `FACTORY_IO/`: avances de escenas, sensores, actuadores y pruebas de simulación.

## Recomendación de formato

- Crea un archivo por avance usando el template `00-template-avance.md`.
- Usa nombres con fecha: `AAAA-MM-DD-descripcion.md`.
- Adjunta evidencias en `evidencias/` para mantener respaldo visual/técnico.
