# TIA_PORTAL-Factory-I-O--Retake

Estructura base para subir y documentar el progreso/avance del desarrollo de proyectos en **TIA Portal** y **Factory I/O**.

## Estructura recomendada

```text
progreso-avance/
├── README.md
├── TIA_PORTAL/
│   ├── 00-template-avance.md
│   └── evidencias/
│       └── .gitkeep
└── FACTORY_IO/
    ├── 00-template-avance.md
    └── evidencias/
        └── .gitkeep
```

## Uso rápido

1. Copia el `00-template-avance.md` del entorno donde estés trabajando.
2. Renombra el archivo con fecha y descripción, por ejemplo:
   - `2026-07-16-configuracion-hmi.md`
   - `2026-07-16-logica-cinta-transportadora.md`
3. Guarda capturas, videos o exports en la carpeta `evidencias/` correspondiente.
4. Sube los cambios al repositorio para mantener trazabilidad del avance.
